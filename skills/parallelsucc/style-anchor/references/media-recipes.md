# Media Recipes

Use these recipes to turn the style contract into repeatable prompts and audit checks.

## Universal Prompt Layers

Build prompts in this order:

1. style label or family
2. core intent
3. invariants
4. item-specific subject slot
5. one approved variation axis
6. negative constraints

Do not shuffle in extra style adjectives unless they are now part of the contract.

## Image Recipe

Use for textures, sprites, icons, posters, illustrations, and other raster outputs.

### Prompt Formula

`[style family] + [core intent] + [fixed visual invariants] + [subject slot] + [one variation axis] + [negative constraints]`

### Texture-Oriented Checks

- Is the palette still inside the approved range?
- Do edges and surface detail behave the same way across the set?
- Is density consistent, or did one item become much busier or flatter?
- Do defects, wear, grain, or polish follow the same logic?
- If the set should tile or loop, did repeat behavior stay consistent?

### Repair Moves

- remove newly introduced visual adjectives
- restate palette and finish more concretely
- reduce subject-specific details that overpower the style
- regenerate only the failed items

## Text Recipe

Use for poems, lyrics, slogans, prose fragments, and naming sets.

### Prompt Formula

`Write [form] in the established style anchor. Keep [voice invariants], use [motif bank], vary only [approved axis], avoid [negative constraints], and target [core intent].`

### Poetry-Oriented Checks

- Did diction stay in the same register?
- Did line length and cadence stay recognizable?
- Did imagery come from the same metaphor family?
- Did the emotional temperature drift brighter, colder, louder, or flatter than planned?
- Did an item become generic because topic language replaced the established voice?

### Repair Moves

- restate the voice and cadence in concrete terms
- swap topic-heavy wording for motif-bank imagery
- tighten the allowed variation axis
- rewrite only the outliers instead of the whole set

## Cross-Medium Translation

When carrying one style across image and text:

- map palette to tonal vocabulary
- map material finish to sentence texture or diction sharpness
- map composition to line movement or information density
- map recurring visual motifs to recurring verbal images

Keep one contract for the style family and translate it, rather than maintaining separate unrelated style briefs.
